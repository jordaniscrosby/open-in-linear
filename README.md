# Open in Linear

Quickly open up tasks in linear with a keyboard shortcut

### How it works

highlight some text (like `ENG-123`) and press `CONTROL+OPTION+COMMAND+L` to open up linear

  <source media="(prefers-color-scheme: dark)" srcset="assets/shortcut-dark.svg">
  <img alt="Mac keyboard with control, option, command and L highlighted" src="assets/shortcut-light.svg" width="600">
</picture>

tickets will open direct and anything else will open a search

## Install

```bash
git clone https://github.com/jordaniscrosby/open-in-linear.git
cd open-in-linear
./install.sh
```

It asks for your Linear workspace and lets you keep the default shortcut or pick your own. Run it again to change either one. 

To remove it, run `./uninstall.sh`.
